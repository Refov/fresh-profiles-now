# Fresh Profiles Now

A job seeker profile platform built with React, TypeScript, and Supabase.

## Features

- **Job Seeker Profiles**: Create and manage professional profiles
- **Candidate Search**: Browse and filter job seekers by skills, location, and work preferences
- **Admin Panel**: Manage profiles and monitor site activity
- **Mobile Responsive**: Optimized for all devices
- **30-Day Expiration**: Profiles automatically expire after 30 days

## Tech Stack

- **Frontend**: React, TypeScript, Vite
- **UI Components**: Shadcn/ui, Tailwind CSS
- **Database**: Supabase
- **Deployment**: hostcreators.sk

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables (see `.env.example`)
4. Run development server: `npm run dev`

## Deployment

The site is deployed on hostcreators.sk with automatic deployment via GitHub Actions.
